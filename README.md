# CMOS Common-Source Amplifier

## Overview

Designed and analyzed a CMOS common-source amplifier using LTspice to study basic analog amplification and transistor-level circuit behavior.

## Objectives

- Understand NMOS common-source amplifier operation
- Design the DC biasing circuit
- Analyze voltage gain
- Study frequency response and bandwidth
- Verify transistor operating conditions through simulation

## Circuit

The project implements an NMOS common-source amplifier with resistive load and appropriate biasing.

## Key Concepts

- NMOS transistor operation
- DC biasing
- Common-source amplification
- Small-signal voltage gain
- Frequency response
- Bandwidth
- Transistor operating regions

## Tools

- LTspice
- Analog circuit simulation
